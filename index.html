이 문서의 역할은 ‘어떤 API인지 알고, 공식 문서 URL을 건네주는 것’까지입니다. 실제 구현은 아래 범용 프롬프트에 빈칸만 채워서 AI 코딩 도구에 맡기세요. 카드마다 있는 프롬프트 복사 버튼은 이 틀에 API 이름과 문서 링크를 미리 채워 줍니다.

사용할 모델 또는 제품: [예: gemini-3.8-flash]

요구사항:
1. 먼저 위 공식 문서를 읽고 최신 인증 방식, 엔드포인트, 요청·응답 형식을 확인한 뒤 진행해줘.
2. API 키는 .env 파일에 저장하고 코드에 직접 쓰지 마. 키가 아직 없으면 어디서 어떻게 발급받는지 단계별로 알려줘.
3. 무료 한도와 과금 방식을 짧게 요약해주고, 호출 실패(401, 429, 5xx) 시 사용자에게 보이는 에러 처리를 넣어줘.
4. 가장 작은 동작 예제를 먼저 만들고 실행 방법을 설명한 다음, 내 서비스 코드에 붙여줘.
5. 현재 프로젝트 구조: [예: Next.js + Supabase]

사용 흐름

  1. 섹션에서 기능을 찾고 카드의 설명·무료 정책·한국 참고를 읽습니다. 처음엔 추천 표시부터 보세요.
  2. 문서 버튼으로 공식 문서를 한 번 열어 회원가입과 API 키 발급 화면을 확인합니다. (대부분 5분)
  3. 프롬프트 복사를 눌러 Claude Code에 붙여넣고 [구현할 기능]만 채웁니다.
  4. AI가 만든 코드를 실행해 보고, 에러가 나면 에러 메시지와 함께 “문서 다시 확인해서 고쳐줘”라고 요청합니다.
키 관리 원칙: API 키는 비밀번호입니다. .env에 두고 .gitignore에 넣으세요. 브라우저(프론트엔드) 코드에 키를 넣으면 누구나 볼 수 있으니, 서버 함수(Vercel · Supabase Edge Functions 등)를 거쳐 호출하는 것이 기본입니다. 지도 SDK처럼 프론트 키가 필요한 경우엔 도메인 제한을 꼭 거세요.
